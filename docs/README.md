# Demo assets

Drop your screen recording here as `demo.gif` (or `demo.mp4`), then uncomment the
`![Demo](docs/demo.gif)` line near the top of the root `README.md`.

Suggested 30–60s recording script:
1. Open the **What-if Simulator** tab and drag 2–3 sliders — show the gauge, badges,
   and factor bars updating live.
2. Switch to **Full Workflow Demo** and run all four steps once (create applicant →
   submit application → evaluate → view history).
3. Show `npx jest` passing in a terminal (12/12).
